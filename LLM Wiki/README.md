# Как пользоваться этой вики

База знаний об AI-поверхности AnalyseTool. Её **пишет и поддерживает агент**, а не вы —
ваша часть — приносить источники и задавать вопросы.

Правила для агента лежат в [`CLAUDE.md`](CLAUDE.md); читать его вам не нужно.

## Что читать

| Хочу | Открыть |
| --- | --- |
| понять, что тут вообще есть | [`wiki/overview.md`](wiki/overview.md) |
| найти страницу по теме | [`wiki/index.md`](wiki/index.md) — каталог всего |
| вспомнить, что и когда решали | [`wiki/log.md`](wiki/log.md) — журнал |

Папка открывается в Obsidian как есть.

## Три вещи, которые можно попросить

Это весь интерфейс. У каждой есть команда (ниже), но можно и словами — агент узнаёт
операцию.

**Вплести источник** — `/ingest`, или просто ссылка в чат.
Агент прочитает, заведёт страницу в `sources/`, вплетёт содержание в существующие
страницы, поправит ссылки и допишет журнал.

**Спросить** — `/query`, или вопрос словами: «что у нас с длинными вызовами?». Ответит по вики, а если вопрос
потребовал настоящего разбора — оставит его страницей в `analyses/`. Так вики растёт
сама: один и тот же вопрос не разбирается дважды.

**Проверить** — `/lint`. Вики полна ссылок на движущийся код; линт находит
пути и имена команд, которых больше нет, битые ссылки, страницы-сироты и дыры.
Стоит просить после заметных изменений в коде.

## Команды

Готовые команды агенту — набирать со слэша:

| Команда    | Что делает                                                                  |
| ---------- | --------------------------------------------------------------------------- |
| `/refresh` | свежий снимок issues в `raw/`, вплетает новое, прогоняет линт, отчитывается |
| `/ingest`  | вплести источник: страница в `sources/`, вплетение, `index`, журнал         |
| `/query`   | спросить; если ответ потребовал разбора — оставит его страницей             |
| `/lint`    | проверка здоровья: битые ссылки, устаревшие пути, сироты — и починка        |

Живут в `.claude/commands/` в корне репозитория — по файлу на команду. Новую добавляйте
туда же: попросите агента, формат он знает.

## Что делаете руками

- Кладёте источники в `raw/` — документы, переписки, транскрипты.
  **Внутри `raw/` ничего не правите и не удаляете.** Это фундамент: если он поплывёт,
  вики перестанет быть проверяемой.
- Всё остальное — через агента.

## Чего здесь нет

Вики не дублирует репозиторий. `ONBOARDING.md`, `src/LLM.md`, `CLAUDE.md` в корне —
это то, что отгружается пользователям и потребляется CI; вики на них ссылается, но не
копирует.

> Нужно в рантайме → репозиторий. Нужно, чтобы понять, сравнить или решить → вики.

## Скрипты

```bash
python scripts/lint.py           # проверка здоровья
python scripts/fetch_github.py   # свежий снимок issues в raw/
```

Только стандартная библиотека, ставить нечего. Подробности — [`scripts/README.md`](scripts/README.md).
