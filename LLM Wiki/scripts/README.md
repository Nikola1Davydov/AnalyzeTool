# scripts/

Скрипты обслуживания вики. Только стандартная библиотека Python — ставить нечего.

Руками их запускают редко: есть команды `/refresh` (снимок → вплетение → линт) и `/lint`,
они лежат в `.claude/commands/` и вызывают эти же скрипты.
Запускать из корня vault (`LLM Wiki/`) или откуда угодно: пути они вычисляют сами от
своего расположения.

## `lint.py` — операция lint

```bash
python scripts/lint.py           # полный отчёт
python scripts/lint.py --quiet   # только проблемы
```

Проверяет всё, что перечислено в разделе «Lint» файла [`../CLAUDE.md`](../CLAUDE.md):

| Проверка | Что ищет |
| --- | --- |
| ссылки | битые относительные ссылки между страницами |
| сироты | страницы, недостижимые из `index` / `overview` / `log` / `CLAUDE` |
| **пути** | каждый процитированный артефакт кода — сверка с рабочей копией на уровень выше |
| sources ↔ raw | файл в `raw/`, который не упомянут ни одной страницей `sources/` |
| незакрытое | `status: stub` и блоки «не проверено» |
| дыры | термин упоминают N страниц, а своей страницы нет |

Код возврата `1`, если есть битые ссылки или несуществующие пути.

**Проверка путей — главная здесь.** Вики стоит рядом с движущимся кодом, и устаревший
путь это не косметика, а ложь, которую агент примет за факт. Слой `raw/` из проверки
ссылок исключён: он неизменяем, и внутри него ссылки принадлежат источникам.

Три таблицы в начале файла стоит пополнять:

- `RUNTIME` — файлы, создаваемые в профиле пользователя, а не лежащие в репозитории
  (`ai-providers.json` и подобные);
- `ELSEWHERE` — существующие, но не в текущей ветке, с указанием где искать;
- `SIBLINGS` — соседние репозитории проекта (`AnalyseTool.FamilyManager` и далее): вики
  цитирует и их, путь ищется рядом с основным репозиторием;
- `TERMS` — термины для поиска дыр и страницы, которые ими владеют.

## `fetch_github.py` — снимки трекера для ingest

```bash
python scripts/fetch_github.py                 # issues + комментарии
python scripts/fetch_github.py --comments      # только комментарии
python scripts/fetch_github.py --date 2026-09-15
python scripts/fetch_github.py --repo owner/name
```

Кладёт датированные файлы в `raw/` и **никогда не перезаписывает существующий снимок** —
слой источников неизменяем. Нужен свежий, задайте другую дату; старый остаётся рядом.

Публичный API без токена: лимит 60 запросов в час, для этого объёма хватает с запасом.
Комментарии тянутся одним репозиторным запросом (`/issues/comments`), а не по одному на
issue.

Скачать — это только шаг 1 операции ingest. Дальше по [`../CLAUDE.md`](../CLAUDE.md):
страница в `sources/`, вплетение в существующие страницы, `index.md`, `log.md`.

## Чего здесь нет и почему

Скрипта, который «пишет вики». Синтез — работа ассистента, а не шаблонизатора; эти два
делают ровно то, что механично и потому переписывалось по несколько раз за сессию.
