# raw/ — неизменяемые источники

Кладите сюда источники. Ассистент ничего в этой папке не правит и не удаляет.
На каждый источник заводится страница-конспект в [`../wiki/sources/`](../wiki/sources/).

Что сюда хорошо ложится:

- транскрипты переписок, где что-то реально выяснили;
- дизайн-заметки и решения, не доехавшие до репозитория;
- статьи, документы, гисты, которые стоит сохранить;
- скриншоты и логи падения, которое стоит запомнить (`assets/`).

**Не сюда**: файлы, которые уже лежат в рабочей копии на уровень выше. На них
ссылаются путём — см. [`../CLAUDE.md`](../CLAUDE.md).

Называйте файлы так, чтобы источник опознавался без открытия:
`2026-08-31-mcp-timeout-transcript.md`, `karpathy-llm-wiki.md`.
